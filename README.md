# 🎓 Student Information App

A student record management app built with **React** and **Tailwind CSS**.

## ✨ Features

- 📝 Add students (name, email, gender, age, state, country, blood group, genotype, department, subject)
- 🎴 Card view with photo avatars
- 📊 Table view with all records
- 🔍 Search by name, department, or state
- 🏷️ Filter by gender, blood group, genotype
- 👥 Stats (total, male, female count)
- 🗑️ Delete students
- 💾 LocalStorage persistence (data survives refresh)

## 🛠️ Built With

- React 19
- Tailwind CSS 4
- Vite

## 🏗️ Installation

```bash
git clone https://github.com/oladiiposaheed/student-info.git
cd student-info
npm install
npm run dev
```
